## The pitch

> GoldfishGPS puts a live GPS tracker on your goldfish so office workers can watch it swim in circles from their desks and charges a dollar when it reaches the exact same corner for the fortieth time today.

## What this program does

`main.ts` writes that pitch — verbatim, 204 characters, one sentence, no trailing newline — to `/output/entry.txt`. Before writing it guards the competition's gates (1–240 characters, single sentence), then reads the file back and verifies it is byte-identical to the pitch, throwing on any mismatch.

## How to run it

```sh
node main.ts
```
